# F1 Race Analysis Web App

## Description

This web application analyzes Formula 1 race data and provides visualizations of driver performance, position changes, and other race statistics.  
It is built using **Python** for backend data processing and **HTML/CSS/JS** for the frontend.

The project is ideal for:

- F1 fans who want to analyze races in detail  
- Learning data visualization and web development  
- Exploring FastF1 and race telemetry data
